# i18n-speed README

## Requirements

- VS Code version needs to equal or greater than `1.100.0`
- Currently this extension only considers the case the workspace has only one folder

## Features

- Go to an i18n json file, press `cmd+1` to insert text from clipboard
- Select one or multiple text in html / ts file, press `cmd+1` to insert text from selections
  - press options key to select multiple text
- `cmd+2` is almost the same as `cmd+1` while it forces to use hash as key
- Add go to definition for i18n identifier in html / ts file
- Add go to references for i18n json file keys
