# i18n-speed README

## Requirements

VS Code version needs to equal or greater than `1.100.0` .

## Features

- Go to an i18n json file, press `cmd+k i` to insert text from clipboard
- Select one or multiple text in html / ts file, press `cmd+k i` to insert text from selections
  - press options key to select multiple text
- Add go to definition for i18n identifier in html / ts file
- Add go to references for i18n json file keys
